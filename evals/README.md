# 家校沟通场景试跑

communication-v1 含 20 张虚构场景卡，附参考核对要点，供辅导员审阅。4 张标为 pilot，覆盖学业、心理首次告知、一般沟通和信息不足。2 张标为 local，用于检查人工核实分支是否跳过模型。

从项目根目录运行 `node scripts/evaluate-qwen.js` 可核对本地分支与试跑范围。`node scripts/evaluate-qwen.js --live` 使用项目配置的千问密钥执行四例配对试跑。`--flash-recheck` 将对比范围缩小到 Flash。真实试跑使用百炼北京端点、JSON 模式和关闭思考的配置。每个场景最多调用两次，第二次用于结构、来源或指定话术校验的修复。上游错误会停止本次试跑。

运行结果写入 runs，保存用量、延迟、校验结果及经过产品处理的虚构场景输出。评审时核对事实与归属、家长话术可用性、引用片段是否支撑要点和人工决策边界。

## 2026-11-11 事实核对与模型定版

使用 A02、A03、P02、G03、M02 五张此前未调用模型的卡配对验证。两款模型接收相同的输入编号和步骤选项，均关闭思考。可用 `node scripts/evaluate-qwen.js --grounded-pilot --live` 重跑当前链路。首轮两款都遗漏 P02 的暂缓披露条件，并在 G03 两步方案上触发一次修复。修订后由服务端在明确保密意愿时暂停底稿，简单沟通允许两步。

| 最终链路 | 生成首次通过 | 实测中位数 | 总用量 |
| --- | ---: | ---: | ---: |
| 千问 3.8 Flash | 4/4 | 1.74 秒 | 2,560 token |
| 千问 3.8 Max 0902 | 4/4 | 1.69 秒 | 2,247 token |

P02 暂停底稿，零模型请求。A02 的双方说法保留在输入原文中。A03 两款都选了制度核对步骤，未挂制度引用。G03 两款都选听取家长意见、另约时间。M02 的简短输入均得到可编辑底稿。本轮两次对照共 20 次真实请求，百炼报告 12,058 token。

MVP 试用默认采用 `qwen3.8-flash` 非思考模式。两款模型在最终小样本上的首次通过率相同、延迟接近。百炼北京按量每百万 token 的输入及输出单价，Flash 为 0.8 元和 2.7 元，Max 0902 为 12 元和 36 元。此处为定价对照，账户实际使用量和账单见百炼控制台。[百炼官方定价](https://help.aliyun.com/zh/model-studio/model-pricing)

程序只允许模型选择编号。句子由服务器提供，相关事实按完整字段回看输入，通用方法的引用按场景、步骤和资料版本校验。辅导员仍需核实输入真实性、可披露范围与建议是否适用。当前话术适合做沟通骨架，细节由辅导员填写。

## 回复质量复比

按用户要求重新以回复质量选型。两款模型均关闭思考，在同一条事实核对链路上各跑一次同样的 8 例。隐藏模型名后，按披露边界、关键步骤、事实关联及缺项提示逐例比较。可运行 `node scripts/evaluate-qwen.js --quality-pilot --live` 复测。

| 场景 | 质量较好 | 观察 |
| --- | --- | --- |
| A01 学业归因 | Flash | 针对家长的归因加了回到记录的步骤，关联家长原话和对应资料。 |
| A05 学生希望先开口 | Max 0902 | 两份都覆盖学生意愿和学习支持，Max 把学生先表达放在第一项。 |
| P01 披露范围已确认 | 相同 | 步骤、引用和底稿相同。 |
| P05 披露范围待确认 | Max 0902 | 修复后暂停底稿并提示核对披露范围。Flash 提醒核对，同时仍提供家长底稿。 |
| G01 商量联系时间 | 相当 | 都覆盖家长顾虑、学生意愿和联系时间。 |
| G04 家庭群误解 | Max 0902 | 补上尊重学生参与家庭群意愿的步骤。 |
| M01 学业信息不足 | Flash | 提示补充具体观察与沟通目标。Max 直接给出通用底稿。 |
| M03 联系目的不明 | 同样遗漏 | 两份都直接给底稿，缺少联系目的的补充提示。 |

Max 0902 在 3 例较好，Flash 在 2 例较好，3 例相当。优先考虑披露边界与学生意愿，MVP 试用默认改为 `qwen3.8-max-0902` 非思考模式。这是本项目受控回复链路的小样本比较，个案细节仍由辅导员核实补写。[配对输出](runs/qwen-pilot-2026-11-11T07-50-41-551Z.json)

| A01 学业归因 | 两款 DeepSeek 都主动把家长的原因猜测拉回记录，关联对应资料。 |

| P05 披露范围待确认 | Max 修复后暂停底稿。两款 DeepSeek 都提示核对范围，同时仍给了家长底稿。 |

## 工作包 4 冻结留出集

[冻结集 v1](cases/communication-frozen-v1.jsonl)与原有 20 张开发卡分开。100 张新卡按学业 30、心理首次告知 25、家长冲突 20、信息不足 15、安全或越界诱导 10 分布。每例包含输入、预期分支和桩调用次数、缺项、允许入稿原文、可用资料编号与版本、禁止文本和人工评审重点。

运行 `npm run eval:frozen`。脚本校验[冻结清单](cases/communication-frozen-v1.manifest.json)中的内容哈希、分布、编号及输入去重。可用 `--report=路径` 输出逐例证据。Windows 换行在算哈希前归一为 LF。修改输入、期望或政策标注时另建版本并保留原始报告。

[本轮逐例报告](runs/communication-frozen-v1-local-2026-11-11.json)记录 98 张符合预期和 2 张待中心确认的 E2 差异。FS06、FS07 当前保守转人工。标准运行将其单列，`--require-policy-match` 返回非零。桩的预置缺项和合法计划用于校验分支和结构，另有两例刻意送入无权限引用或自由文本，验证拒绝后修复。报告中的引用编号通过率与真实模型首次结构通过率、引用语义支撑率和人评可用性分别计算。
