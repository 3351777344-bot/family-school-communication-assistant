# 数据处理与隐私边界（原型阶段）

## 当前行为

- 离线演示版在浏览器内展示固定示例，不调用模型接口。
- 模型联调版由本机 Node.js 服务接收表单；连接模型时，请求会发往 `API_BASE` 配置的模型 API。
- 服务端仅替换部分常见号码格式：手机号、身份证号、学号、邮箱和座机。姓名、班级、可识别家庭信息、聊天原话及其他间接识别线索不能保证被发现。
- 模型只返回步骤、输入和资料编号，服务端验证后组合固定话术。工作台的输入证据为脱敏后的原文，仍需核对真实性和可告知范围。
- 本地服务控制台记录请求方法、接口路径和耗时，不记录请求正文。模型服务方的数据处理、日志和留存规则尚未核实。
- 受控本地试点演练强制离线。其请求日志使用固定路由分类及随机请求号，不记录原始路径、查询串、业务正文或凭据。完整字段和校内待审规则见[访问数据与日志规则](../handoff/工作包5_访问数据与日志规则.md)。
- 学校平台的访问权限、日志、保存期限及刷新或关闭页面后的处理方式均待确认。当前不承诺“不会保存”或“不会留痕”。

## 试用要求

1. 只使用项目组编写或由试用者改写的虚构场景。
2. 不输入姓名、学号、班级、咨询原话、真实个案、可识别家庭信息或截图。
3. 不向试用者分发项目 API key。需要模型对照时，由项目组在明确说明模型服务会收到脱敏后文本的前提下，用虚构场景演示。
4. 未确认校内数据政策和模型服务方规则前，不接入真实业务数据。

## 待决策

- 是否允许使用外部模型 API，是否需要校内模型或代理服务。
- 访问控制、服务日志、模型请求留存和页面关闭后的数据处理规则。
- 脱敏覆盖范围、人工检查责任和安全事件处理流程。
