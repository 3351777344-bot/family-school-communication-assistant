# 待确认事项与交接清单

本文件只记录需要校内确认的内容。未确认的知识库条目继续保持 `待审核` 或 `待核对`，不要改成可公开引用状态。

## 校内确认事项

| 事项 | 需要确认 | 影响位置 |
|---|---|---|
| 学业警示流程 | 等级、后续要求、解除条件、决定角色及可引用版本 | `app/kb_v3.json` |
| 心理危机流程 | 提醒条件、联系对象、专业介入、转介入口及对外用语 | `app/kb_v3.json`、服务端安全提示 |
| 可告知范围 | 心理首次告知的核对步骤、由谁确认、保密及例外如何处理 | 工作台可告知范围和披露暂停提示 |
| 数据处理 | 外部模型是否获准、访问权限、日志、服务方留存、刷新/关闭页面行为 | `docs/product/数据处理与隐私边界.md` |
| 资料开放范围 | 公开、审批后、禁止使用的实际资料清单及审核人 | `docs/research/资料清单_处置结论_v1.xlsx` |
| 三类场景候选卡 | 核对 10 张候选卡的措辞、出处、使用范围、审核人和有效期 | [候选资料卡](../../app/reference-cards.json) |
| 五步流程 | 正式名称、每一步条件与责任人 | `app/server.js`、两个 HTML 原型 |
| 危机场景演示 | 是否纳入、触发方式、最终提示语 | `app/家校沟通助手_原型v3.html` |
| 法律表述 | 法条原文、适用范围与审核人 | `app/kb_v3.json` |
| 正式名称 | 主标题；副标题暂定“辅导员家校沟通辅助工具” | 页面与对外材料 |

## 当前工程状态

- 当前知识库：`app/kb_v3.json`，18 条；旧版位于 `archive/legacy-prototype/`。
- 当前服务：`app/server.js`，只保留健康检查和沟通准备接口；自由聊天接口已从当前版本移除。
- 危机场景按钮暂禁用；关键词只触发人工核实提醒，不判断或排除风险。
- 模型版输入会发送到 `API_BASE` 配置的服务。正则只覆盖部分号码，不能可靠去除姓名、班级和间接身份信息。
- 在线试用仅使用虚构场景；数据规则未获确认前不收集真实个案。

## 确认后变更要求

每次更新知识库都记录审核人、资料版本/日期、来源和变更摘要；只把经确认可引用的资料状态改为“公开文件”。校内流程确认前，保持通用提示，不补写条款号、期限或具体处置动作。
