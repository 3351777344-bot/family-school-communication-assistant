# 家校沟通助手访问数据与日志规则

下列校内规则为审批草案。校方核定后填写具体周期、访问人、存储位置和责任人。本地演练的实际行为单列，供核对差异。

| 数据或记录 | 本地演练实际行为 | 试点审批草案 |
| --- | --- | --- |
| 场景输入、事实、稿件和勾选 | 仅虚构输入。应用在本次请求和页面中处理，无业务数据库。刷新或关闭清除页面状态，浏览器保留已读说明标记。 | 默认仅虚构输入。拟继续采用单次工作台，需批准可处理字段、页面行为、是否允许保存，以及批准后使用的沟通渠道。 |
| 账号和授权 | 项目外本地文件保存虚构账号编号、角色、场景和随机口令摘要。演练进程启动时载入。 | 由学校身份体系提供身份。有效名单、场景、起止日期、撤销方式和审计权限由校方指定。 |
| 运行日志 | 控制台记录 UTC 时间、服务端请求号、固定路由分类、请求方法、HTTP 状态、耗时、权限配置版本、离线模式和可用结果分支。 | 拟采同类元数据，另记录获批的应用、规则、资料和模型版本。是否需关联访问主体由校方审批，在 IAM 审计侧分开处理。 |
| 业务正文及凭据 | 应用日志不包含输入、底稿、授权头、口令、稿件上下文、账号编号或原始 URL 和查询串。演练不会读取项目模型配置或向模型发送文本。 | 日志排除正文、身份线索、咨询内容、凭据与令牌。代理、监控、错误采集和备份也要逐一核验。 |
| 反馈与验收证据 | 用虚构卡号、匿名编号、版本和请求号记录，资料卡与演练证据分开。 | 只保留批准的虚构或合成材料。记录与截图先核对可识别信息，存于批准位置。 |
| 外部服务 | 本地演练强制离线。 | 外部 API 默认关闭。书面批准后核定可发数据、服务方处理与保留期限、再利用权限、删除和事件处置。 |

## 访问和留存待签项

- 运行日志限指定平台维护人员按最小权限查看，中心和辅导员通过匿名证据反馈问题。建议审批时讨论运行日志 14 天、虚构验收证据在试点结束后 30 天的拟议周期。校方需分别确认实际期限、起算点、到期清理责任和例外批准，确认前不启用持久集中采集。
- 名单及 IAM 访问审计由校方管理。审批应说明谁可查询、如何撤销、是否保留撤销记录和保留期限。当前本地配置文件和临时口令只供演练，演练结束后删除或作废。
- 停用后由负责人确认入口关闭、权限撤销、日志与证据按批准规则处理、备份同步到期。由平台维护人记录处理时间和复核人。涉及异常时先遵循校内事故处理及获准的证据保全范围。
- 信息误输时停止继续提交和复制，使用学校批准渠道反馈时间、版本、请求号和问题类型。无需在工单中粘贴输入、底稿、凭据或完整页面截图。

## 本地演练的验证边界

本地账号通过回环 HTTP Basic 认证，仅验证允许、拒绝、按场景授权及撤销回滚。生产所需的学校身份登录、会话时效、代理信任、HTTPS、网络边界、集中日志、实际删除和目标环境回滚均待校方批准并验证。撤销能阻断后续请求，已显示或已复制的内容应按试点退出规则处理。
