# 模型资料准备模板

资料先交给项目负责人审核，分别标明允许人工阅读、检索引用、外部API处理和训练的范围。不要提供真实个案、姓名、学号、班级、原始咨询/聊天记录。密钥只提供本机安全文件路径，不填写到此文档。

专业书籍可先提供书名、版次、相关章节及页码，以及经授权的短摘录或教师自己写的方法摘要。针对某条沟通动作只提供能支持该动作的内容。获得阅读权限后，仍需单独确认能否向外部模型发送摘录。校内流程另用经学校确认的材料核对。

## A 学校流程与知识卡

| 字段 | 填写内容 |
|---|---|
| source_id / card_id | 唯一编号 |
| 标题、版本、日期 | 学校流程或书籍/笔记信息 |
| 出处 | 文档名称、章/节/页码、公开链接（如有） |
| 允许使用范围 | 人工阅读/检索引用/外部API/训练，逐项确认 |
| 原则摘要 | 教师自己写的一到三句话 |
| 适用场景 | 学业/心理首次告知/一般沟通等 |
| 不适用与禁用 | 哪些情境不能照用、不能作什么推断 |
| 建议表达与反例 | 可以如何表达、哪种说法有误 |
| 审核人/日期/状态 | 未审核不作为校内制度依据 |

## C 错误与修改对

记录：case_id、模型/提示词/知识库版本、原输出、教师修改结果、修改原因（事实/依据/表达/边界/缺少信息）、严重程度、审核人。原输出和改写不能包含真实身份信息。对外API处理与训练范围需另行确认。

## D 账号配置说明

记录服务商、百炼地域/工作空间、允许调用模型ID、可否调优、预算上限、密钥在本机的文件路径。不要把key值贴到代码、文档或群里。
