# 讲义与课件图片初步核查

本记录针对教师材料中的 DOCX 与 PPTX 嵌入媒体，按内容哈希去重：434 个图片引用对应 184 个不同文件，其中 131 个可转为位图、53 个为 SVG。已对 131 个位图运行本地 OCR 并查看缩略图总览；81 个 OCR 文本为空，不能据此断定图片没有文字或隐私。53 个 SVG 经结构扫描未发现 text、image、脚本或外链标签，仍不代表对完整页面进行了人工核查。

总览可见人物照片、活动场景、机构标识、表单和参考书封面等；这些原始图像及其文字均未纳入知识库。为避免个人、机构及间接身份信息泄露，知识库只保留人工核对来源后提炼的非个案要点。

限制：缩略图和 OCR 不能代替对原图逐张细查；PPT 的原生形状、图表、备注、组合图形及其他嵌入对象并非一定属于媒体文件，仍需逐页检查。讲义、课件的全文和图片尚未全部人工审阅或标记为完成脱敏。OCR 输出、原图、哈希索引和缩略图存放在项目外层 tmp，均按未脱敏资料处理，不应外发。
