# 家校沟通助手本地权限与回滚演练

本入口仅供同一台电脑的虚构演练。受控模式只监听 `127.0.0.1`，强制离线，使用单独权限文件。正常离线演示可继续按[本地运行说明](本地运行与回滚.md)启动。校内正式开放条件见[审批与范围](../handoff/工作包5_校内试点审批与范围.md)。

## 自动验证

```powershell
npm run build:web
node --test tests/pilot.test.js
```

测试生成临时虚构账号并随机选择回环端口。验证匿名和错误凭据拒绝、观察角色限制、辅导员场景权限、草稿跨账号使用拒绝、跨站请求拒绝、日志无正文、配置失效时停止启动。回滚测试在同一端口依次运行基线、变更和恢复配置，最后核对已撤销账号仍拒绝、旧稿件上下文失效、保留账号能用恢复场景重新生成。

## 手动启动受控工作台

在项目根目录执行下面的命令。示例在独立临时目录生成两个虚构账号和权限文件。仅在本机打开临时凭据文件，使用浏览器弹出的认证框登录。

```powershell
$pilotDir = Join-Path $env:TEMP ('family-school-pilot-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $pilotDir | Out-Null
@'
const fs = require('node:fs');
const path = require('node:path');
const { randomBytes, createHash } = require('node:crypto');
const dir = process.argv[2];
const users = [
  { id: 'synthetic-counselor', role: 'counselor', scenes: ['xueye'] },
  { id: 'synthetic-observer', role: 'observer', scenes: [] }
].map(user => ({ ...user, password: randomBytes(32).toString('base64url') }));
const accounts = users.map(({ password, ...user }) => ({
  ...user, tokenSha256: createHash('sha256').update(password).digest('hex')
}));
fs.writeFileSync(path.join(dir, 'policy.json'), JSON.stringify({ revision: 'local-v1', accounts }, null, 2));
fs.writeFileSync(path.join(dir, 'local-credentials.txt'), users.map(u => u.id + ' ' + u.password).join('\n'));
'@ | node - $pilotDir
if ($LASTEXITCODE -ne 0) { throw '未能生成本地演练配置' }
$env:LOCAL_PILOT_POLICY_FILE = Join-Path $pilotDir 'policy.json'
$env:PORT = '8791'
npm run start:pilot-local
```

按终端显示的 `http://127.0.0.1:8791` 打开。使用不同的浏览器配置或独立会话分别验证两个角色。辅导员可打开新版工作台，只有学业警示可选。观察账号只可打开 `/api/health`。退出时关闭演练页面和浏览器会话，并停止专用终端进程。不要把临时凭据放入仓库、页面 URL 或证据。演练后清理临时文件。

## 停用与回滚

1. 通知演练人员关闭工作台。停掉本次终端进程，确认端口不再响应。记录当前配置版本、运行状态和拟恢复的范围。
2. 取出已验证的上版场景与角色规则，与当前有效名单重新合成一份配置。保留撤销和轮换结果，分配新的配置修订号。权限不确定时保持停用。
3. 使用同一个受控启动命令加载恢复配置。先检查未认证和已撤销账号仍被拒绝，再用有效账号核对健康响应的配置版本、离线状态、场景范围和重新拟稿。进程重启会使旧稿件上下文失效，已打开页面需刷新或重新进入。
4. 本地验证通过后记录结果。目标校内环境的 IAM、代理、审计、应用制品和配置回滚，须在正式审批后依校方流程另行演练。

演练权限文件只在启动时读取。变更账号、口令或场景后需要重启。若文件缺失、无效或包含重复账号，受控模式会停止启动。设置了演练权限文件的终端若误用普通启动命令，服务也会停止启动。普通演示请使用单独终端。
