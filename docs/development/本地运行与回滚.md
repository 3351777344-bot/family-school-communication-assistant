# 家校沟通助手本地运行与回滚

当前候选版面向虚构数据的本机演练。功能包含首次使用说明、三类场景准备、要点详情、资料和事实核对、披露暂停、信息不足、安全人工提醒、底稿确认及后续勾选。演练安排见[演练与验收手册](../trial/工作包4_演练与验收手册.md)。

## 启动离线工作台

准备 Node.js 22.12 或以上版本，在项目根目录打开终端。安装按锁文件固定依赖，启动命令会构建新版前端并强制离线示例。

```powershell
npm ci
npm run start:mock
```

打开 [本地工作台](http://127.0.0.1:8787)，页头应显示“离线示例 · 不调用模型”。只用手册选出的虚构卡，首次确认使用说明，再开始演练。健康检查 [GET /api/health](http://127.0.0.1:8787/api/health) 应返回 `mock: true`。离线模式不需要 API 密钥，演练结束在该终端按 Ctrl+C 停止。若端口被占用，可在专用终端设置 `$env:PORT='8789'` 后重启，按终端打印的新端口打开。

离线示例使用固定话术和本地门禁，E1 明确缺项、P05 和 E2 可直接演练。对需要模型识别的其他缺项，只在本地自动回归中用桩复核分支。若要演练接口失败或取消，先执行 `npm run build:web`，再执行 `node scripts/start-ui-fixture.js`，打开 [本地故障演练页](http://127.0.0.1:8790)。该桩针对学业场景，第一次成功、第二次失败、后续延迟。

## 自动回归与证据

```powershell
npm run typecheck
npm run build:web
npm test
npm run eval:frozen
```

保存逐例结果可运行 `npm run eval:frozen -- --report=本轮回归.json`。冻结集核对 SHA-256 和 100 个独立编号。标准命令失败表示工程断言有差异。加 `--require-policy-match` 后，待中心确认的分支差异也会令命令返回非零。当前 FS06、FS07 仍有该差异，详见[待整改清单](../handoff/工作包4_待整改清单.md)。

保留候选源码与锁文件、冻结集及清单、逐例回归报告、资料版本和实际演练记录。版本回退前要能定位到经过同一套检查的源码版本。当前生效的原有通用参考仍标为待核实，10 张新候选卡等待审批。回归报告中的源码指纹用于核对本轮的生成、校验和资料版本。

## 常见问题与停用

| 现象 | 处理 |
| --- | --- |
| 页面打不开或仍显示旧页面 | 在启动终端查看构建和端口，确认打开的是打印的本机地址。用 `npm run start:mock` 重新构建启动。 |
| 生成失败、超时或额度不足 | 保留当前页面的输入和编辑。记录错误码及虚构场景编号，按需重试或打开人工协助。 |
| 旧稿复制按钮不可用 | 核对当前输入并重新生成，再完成底稿核对和确认。 |
| 刷新后草稿、事实选择或后续勾选清空 | 这些内容属于当前页面，需重新输入和核对。浏览器只记住已读说明。 |

发现披露、引用或人工提醒问题时，先在启动终端停止进程。需继续虚构流程演练时，用经过验证的候选源码在单独目录执行离线启动。回退到已保存的候选版本前，重跑本页回归及受影响的冻结卡，核对健康检查，再恢复演练。当前工作目录和问题证据应保留，已有编辑勿用清理命令覆盖。

模型接入须按学校确认的范围另行启用。主模型当前配置是 DeepSeek Flash 非思考模式。试用材料和报告只分发虚构输入、匿名记录及相应版本号。密钥只由运行人员维护在本机配置中。
