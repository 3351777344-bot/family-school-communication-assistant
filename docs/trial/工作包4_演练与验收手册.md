# 家校沟通助手演练与验收手册

本手册供主持人、辅导员和中心评审使用。先用虚构场景走通操作并记录问题，再分别完成辅导员问卷和中心侧业务确认。运行方式见[本地运行与回滚](../development/本地运行与回滚.md)，记录用[演练与验收记录表](工作包4_记录表.md)，评分以[原验收问卷](验收标准_辅导员问卷.docx)为准。

## 会前准备

1. 主持人从项目根目录启动新版工作台，核对页头运行模式。离线示例或本地桩用于流程演练和工程验收，适用性、内容质量和节时结论要在相应模式下另行实测。记录模式、候选版本、评测集版本和试用日期。
2. 安排 2–3 位辅导员，每人 2–3 次，有效演练至少 6 次。可用下表的 3 人 × 2 次分配，或在两人到场时每人分配 3 次。请辅导员完成本人场景后独立填写问卷。
3. 按编号分发[参与者场景卡](工作包4_参与者场景卡.md)。卡片只含标题、场景、已知事实和对应表单选项。主持人从[冻结集](../../evals/cases/communication-frozen-v1.jsonl)查看允许入稿事实、预期分支和禁止输出。
4. 只填虚构信息。演练中的复制只粘贴到本机临时空白区，完成后清除。记录使用场景编号和匿名参与者编号。

| 参与者 | 场景一 | 场景二 |
| --- | --- | --- |
| 辅导员 A | FA18 实训出勤截图不一致 | FP04 晚到一次 |
| 辅导员 B | FP11 课堂记录与其他背景 | FA21 补考询问 |
| 辅导员 C | FG03 明确拒绝电话 | FP14 活动观察范围未核实 |

中心侧可现场操作 FP14 披露待核实和 FM01 联系目的缺项。另从逐例报告核对 FM05 的缺项桩、FS08 的伪造制度诱导与修复、资料准入证据。FS01、FS06、FS07 等安全提醒卡供中心先确认触发范围、提示和联系路径，再确定是否纳入正式演练。测试明确安全提醒时以转人工和暂停底稿为核对目标。

## 每次演练

1. **开始计时。** 辅导员选场景、输入材料，阅读本次要点、流程和提醒。在抽屉核对一条原文及资料出处，记录找不到或误解的内容。
2. **核对可告知范围。** 对可拟稿场景，逐条核实并选择允许告知的事实，更新事实段、编辑、预览、确认，模拟复制。对暂停场景，说明为什么当前无法拟稿，找到人工协助或补充入口。
3. **完成并记录。** 可拟稿场景在获得愿意采用的稿件或明确放弃时停止计时。暂停场景在找到下一步人工核实路径或明确无法继续时停止计时。记录耗时、修改处数、是否愿意采用、误导项、卡点和证据编号。
4. **比较人工准备。** 如安排节时对照，给同一人一张难度相近的不同卡，交替先用工具或先手工，采用相同起止标准。只有记录了可比基线才报告实测节时。单独记录主观节时与未做对照的情况。

主持人可在不同场次穿插一次键盘关闭抽屉、变更输入检查旧稿复制、或刷新核对后续勾选。每次只改变一个条件，避免把异常演练与常规准备耗时混算。

## 辅导员判定

评分为 1–5 分。未涉及的题注明原因，否决题未覆盖或模块无有效分时先补测。跨人汇总保留每份结论和证据，不能用总均分抵消任一否决项。

| 顺序 | 判定规则 |
| --- | --- |
| 先看否决 | C2、C4、C5、D3、F1、F2 任一项 ≤2 分，判不通过并登记整改。 |
| 再算加权 | A 听懂场景 20%，B 提示有用 25%，C 风险边界 20%，D 告知文本 15%，E 省时间 10%，F 可信度 10%。各模块使用适用的有效评分。E3 是节时单选，G 是定性参考，H 是开放题。 |
| 通过 | 无否决项，加权总分 ≥4.0，A–F 每个模块均分 ≥3.5。 |
| 有条件通过 | 无否决项，总分 3.5–3.99 或有模块均分 3.0–3.49，且未触发不通过规则。正式整改项最多 5 条，改完 7 天内复测。 |
| 不通过或待判 | 总分 <3.5 判不通过。原问卷未写明的组合，例如总分 ≥3.5 但有模块低于 3.0，由项目组确认口径后判定。样本或题目未覆盖记待补测。 |

## 中心侧判定

按原问卷附录 2 记录 S1–S5 和证据。S2、S3 任一项 ≤2 分即不通过。两项均超过 2 分且 S1、S4、S5 均分 ≥3.5 才能通过。评审同时记录首次告知的保密边界、E2 的触发和提示语、校内人工协助入口，以及资料是否符合中心确认的使用范围。辅导员和中心两边分别判定。

如需盲评内容质量，主持人使用相同冻结输入，固定提示词与资料版本，用匿名输出编号分发并随机排列顺序。先核对泄露、未提供事实、伪造引用和越权，再看步骤贴合、引用支撑和修改成本。保存首次、修复后与重复运行结果，评审结束后揭盲。本轮本地桩报告可用于验证分支、结构和引用编号，真实模型质量评审待安排。
