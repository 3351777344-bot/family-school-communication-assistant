# 前端工作台

React 19 + TypeScript 7 + Vite 8。依赖版本由根目录 package-lock.json 锁定。生产构建由现有本地 Node 服务提供，API 路径不变；没有新增外部托管或用户账号。

## 文件职责

- `src/App.tsx`：组合工作台、服务状态、请求与替换确认。
- `src/state.ts`：纯 reducer，统一保存输入、生成结果、底稿、核对确认、折叠与请求标识。
- `src/api.ts`、`src/types.ts`：API 访问、基本结构检查与前端类型。
- `src/components/InputPanel.tsx`：情况表单与生成操作。
- `src/components/Results.tsx`：四个核心结果、要点详情、预览与人工确认。
- `src/components/Dialog.tsx`：原生 dialog、键盘取消、关闭后焦点返回。
- `src/styles.css`：响应式布局。页面整页滚动，输入与结果容器不设置吸附或内部滚动。
- `src/state.test.ts`：编辑保留、确认失效、请求失败/取消、过期响应等回归。

## 开发与验证

从项目根目录运行：

```powershell
npm ci
npm run start:mock
# 另一个终端，可选热更新开发页
npm run dev:web
npm run typecheck
npm test
```

`npm start` 和 `npm run start:mock` 会先构建到 `dist/web`。`vite.config.ts` 禁用环境文件加载；客户端不包含服务商密钥。API 服务只开放 HTML 和受限的构建 JS/CSS 资源，不开放项目目录。

手工复现失败保留：运行 `node scripts/start-ui-fixture.js`，打开 `http://127.0.0.1:8790`。此工具仅连接本机假接口，不使用真实模型。第一次成功、第二次返回503、后续延迟3秒，便于验证主动取消。该脚本使用合成密钥覆盖环境，不修改 `.env`；结束后 Ctrl+C 关闭。

## 状态约定与限制

首次进入会先显示使用说明。浏览器只记录该版说明已读，页头可以随时重开。要点详情在桌面使用右侧抽屉，在窄屏全屏打开。可用 Tab 浏览、Escape 关闭。关闭后焦点回到原入口。

页头和相关结果均可打开人工协助。生成中打开协助会取消本次等待，提示会按当前结果引导校内人工核实。实际联系由辅导员通过学校现有渠道完成。后续事项的勾选只保留在本次结果，刷新、关闭或成功替换结果后清除。

修改底稿会清空四项核对与旧确认；折叠仅改变可见性。确认绑定输入版本、生成编号和底稿修订。新生成成功后替换结果并重置核对；失败和取消保留旧结果。请求编号和输入版本阻止迟到结果覆写。取消仅中断浏览器接收与页面更新，尚未将取消信号传递到服务商；不能保证已发出的真实请求停止计费。

输入变化后旧稿仅供回看，不能确认或复制；恢复原输入也需要重新生成。场景或事实变化会把已确认的可告知范围重置为待确认。页面内容保存在内存，刷新或关闭会丢失。

结果区可对照本次输入原文，点开要点查看关联的输入和支持该步骤的资料。心理健康首次告知须在表单中明确核实可告知范围。缺项、披露待核实和安全人工核实分支均暂停提供底稿。

“逐条核对事实”保留原文片段和可识别的来源、时间。先核对来源和原文，再选择告知范围和要纳入的条目。点击“更新底稿事实”，本地服务按本次输入验证选择并组合事实段。事实段和可编辑话术一同进入预览和复制。撤回许可时，关联事实即时移出并撤销确认，手工编辑的话术保留。恢复生成稿只恢复话术。
