# 前端工作台

React 19 + TypeScript 7 + Vite 8。依赖版本由根目录 package-lock.json 锁定。生产构建由现有本地 Node 服务提供，原表单 API 保留，新增分析与按核对清单生成接口；没有新增外部托管或用户账号。

## 文件职责

- `src/App.tsx`：组合首页与 Agent 页面、服务状态、请求与替换确认。
- `src/navigation.ts`：首页及四个 Agent 的哈希路由，支持浏览器前进、后退与直接访问。
- `src/components/AgentHome.tsx`：家校工作台的四个 Agent 入口。
- `src/state.ts`：纯 reducer，统一保存输入、生成结果、底稿、核对确认、折叠与请求标识。
- `src/api.ts`、`src/types.ts`：API 访问、基本结构检查与前端类型。
- `src/record-import.ts`、`src/components/RecordImport.tsx`：本地文件提取、来源标签、勾选编辑和明确替换预览。
- `src/analysis.ts`：分析结果原文定位检查、核对与入稿选择类型及筛选。
- `src/components/AnalysisWorkbench.tsx`：粘贴记录、独立版本、人工核对、获准条目生成与错误恢复。
- `src/practice.ts`、`src/components/PracticeWorkbench.tsx`：虚构角色卡、多轮家长演练、显式结束和带回合依据的复盘；请求编号及输入快照用于重试恢复。
- `src/components/InputPanel.tsx`：情况表单与生成操作。
- `src/components/Results.tsx`：四个核心结果、要点详情、预览与人工确认。
- `src/components/Dialog.tsx`：原生 dialog、键盘取消、关闭后焦点返回。
- `src/styles.css`：响应式布局。页面整页滚动，输入与结果容器不设置吸附或内部滚动。
- `src/state.test.ts`：编辑保留、确认失效、请求失败/取消、过期响应等回归。
- `src/practice.test.ts`：演练会话版本、评分与引句校验、请求重试，以及前后端离线契约回归。

## 开发与验证

从项目根目录运行：

```powershell
npm ci
npm run start:mock
# 另一个终端，可选热更新开发页
npm run dev:web
npm run typecheck
npm test
```

`npm start` 和 `npm run start:mock` 会先构建到 `dist/web`。`vite.config.ts` 禁用环境文件加载；客户端不包含服务商密钥。API 服务只开放 HTML 和受限的构建 JS/CSS 资源，不开放项目目录。

手工复现失败保留：运行 `node scripts/start-ui-fixture.js`，打开 `http://127.0.0.1:8790`。此工具仅连接本机假接口，不使用真实模型。第一次成功、第二次返回503、后续延迟3秒，便于验证主动取消。该脚本使用合成密钥覆盖环境，不修改 `.env`；结束后 Ctrl+C 关闭。

## 状态约定与限制

默认进入 Agent 首页，点击卡片进入相应界面。首页展示学生信息分析、家校沟通助手、场景模拟和沟通复盘四个入口；未启用的能力显示「暂未开放」。首次进入可用工作页时显示简短使用提示，浏览器记录已读，页头「使用帮助」可随时重开。要点详情在桌面使用右侧抽屉，在窄屏全屏打开。可用 Tab 浏览、Escape 关闭。关闭后焦点回到原入口。

页头和相关结果均可打开人工协助。生成中打开协助会取消本次等待，提示会按当前结果引导校内人工核实。实际联系由辅导员通过学校现有渠道完成。后续事项的勾选只保留在本次结果，刷新、关闭或成功替换结果后清除。

修改底稿会清空四项核对与旧确认；折叠仅改变可见性。确认绑定输入版本、生成编号和底稿修订。新生成成功后替换结果并重置核对；失败和取消保留旧结果。请求编号和输入版本阻止迟到结果覆写。取消仅中断浏览器接收与页面更新，尚未将取消信号传递到服务商；不能保证已发出的真实请求停止计费。

输入变化后旧稿仅供回看，不能确认或复制；恢复原输入也需要重新生成。粘贴流程的场景或记录变化使旧分析与旧底稿过期；重新分析后条目默认待核对、未允许入稿。页面内容保存在内存，刷新或关闭会丢失。

结果区可对照本次输入原文，点开要点查看关联的输入和支持该步骤的资料。原表单中的学生保密意愿或披露待核实会显示提示，由辅导员核实可告知范围；一般缺项显示通用参考，安全人工核实分支不提供底稿。

## 粘贴或导入记录

服务端健康检查返回 `analysisEnabled: true` 时开放首页「学生信息分析」入口（`#/analysis`）；「家校沟通助手」（`#/form`）提供原表单。各入口保留本次页面中的输入与编辑，返回首页不会清空。设置 `ANALYSIS_ENABLED=0` 并重启服务可停用分析入口。

新入口接收最多 1500 字纯文本及场景。点击分析调用 `POST /api/analyze`，展示每条原文位置、编号、来源、类型、不确定性、说法冲突和建议追问。核对与允许入稿是两个独立选择，默认均不选；只有同时已核对且允许入稿的条目发送至 `POST /api/prepare-from-analysis`。人工补充最多 400 字，保留原文来源，更正后需要重新核对。

记录、场景和条目选择变化都会使旧底稿过期，旧稿不能编辑、确认或复制。分析输入版本与本地底稿版本分开维护；输入版本以当前时间初始化并单调递增，避免刷新页面时与仍在有效期内的服务端会话版本冲突。分析和生成各自可重试；同步请求锁、取消信号、操作序号和输入版本共同阻止重复提交及迟到响应覆写。服务端会话过期或重启后需重新分析。

结果页复用原有四项人工核对、可编辑底稿和复制操作。“逐条核对事实”仅供核对来源，不在结果页重新决定入稿授权；调整授权应回到分析清单重新选择并生成。离线示例有明确标记，不代表真实模型效果。页面输入和编辑均只在内存保留，刷新后丢失。

文件导入支持不超过 5 MiB 的 PDF、DOCX、XLSX，旧版 DOC/XLS 和扫描 PDF 的 OCR 不在本期范围。选择文件后点击「提取并预览」，通过 `POST /api/import-record` 将文件交给本地服务提取，不请求模型。页、段、表格行分段显示；勾选后可编辑片段和来源标签（例如移除工作表名中的身份信息），完整预览包含来源标签，合计最多 1500 字。超限会阻止填入，不自动截断。完整文件名只用于本地预览，不自动放入分析输入。

点击「替换并填入本次记录」才会替换原输入并使旧分析、底稿过期，不自动分析或生成。PDF 多栏顺序与表格行列含义须人工校对；提取原文不等于已核实事实。失败、取消、换文件、修改记录或场景不会让迟到的提取结果覆盖当前记录。导入预览和编辑只保存在当前页面内存。

## 场景演练与复盘

健康检查的 `practiceEnabled` 为 `true` 时开放「场景模拟」（`#/practice`）与「沟通复盘」（`#/review`）。两页共享本次演练会话；复盘无对话时引导进入场景模拟，结束演练后在复盘页主动生成反馈，点击引句返回模拟页并定位原话。选择预置虚构案例、查看家长角色卡及评价草案后开始；每条消息不超过1000字，每次最多20个辅导员回合。主动结束后才能另行请求复盘，结束不自动评分。复盘按五项草案展示反馈，无适用证据时不评分；点击引句可滚动并聚焦到对应辅导员回合。

切换入口或打开人工协助会暂停等待，保留原请求编号与输入快照。重新进入可重试当前步骤，恢复服务端已经完成的结果。页面刷新不会恢复旧对话；本入口不读取原表单或分析材料，也不在浏览器永久保存消息。停用、临时状态和验收限制见[第二阶段实施与验收](../../docs/development/多Agent第二阶段实施与验收.md)。

练习者说得差、提及风险词或不用固定话术仍可继续及复盘，问题原话可作负面证据。安全校验针对模型生成的角色回复和改进建议。角色回复修复后仍不合格时，`replyUnavailable` 提示本轮练习发言已保存，仍可结束后复盘。
